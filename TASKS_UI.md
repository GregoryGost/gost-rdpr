# Задача интерфейса: последняя попытка резолвинга

- [ ] **Показать дату последней попытки в карточке домена.**

   Репозиторий реализации: [gost-rdpr-ui](https://github.com/GregoryGost/gost-rdpr-ui).
   Зависимость: backend-задача P1-19 закрыта; поля добавлены в ответы API.
   Описание и результаты: [TASKS_ARCHIVE.md](./TASKS_ARCHIVE.md).

   Расширить существующие типы домена полями `last_attempt_at` и `last_attempt_at_hum`, допускающими NULL.
   Backend возвращает числовую дату и строку даты по существующим соглашениям API в списке, поиске и карточке.
   Дата относится к последней завершённой сохранённой попытке, включая частичный результат и ошибку.
   У старых доменов начальное значение может быть перенесено из известной `last_resolved_at`.

   Добавить одну строку «Последняя попытка» в существующую карточку домена, используя установленные
   в интерфейсе правила отображения дат и отсутствующих значений. NULL не должен давать ошибку или дату эпохи.
   Сохранить существующие статусы, фильтры, статистику, элементы управления и отображение успешной сверки.
   Изменения backend и добавление истории попыток не входят в эту задачу.

   Проверить отображение заполненной даты и NULL, загрузку карточки из списка и поиска, обновление после
   успешной, частичной и неудачной попытки. Диагностическая проверка без сохранения не должна менять дату.
   Выполнить применимые проверки репозитория интерфейса.
